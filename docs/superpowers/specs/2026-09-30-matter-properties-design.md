## 1. 목표

### 1-1. 학습 핵심
**"물질의 특성은 양에 관계없이 물질마다 정해져 있다. 그래서 특성으로 물질을 알아내고, 특성의 차이로 섞인 것을 가른다."**

- 밀도·용해도·녹는점·끓는점이 물질의 신분증이다. 질량·부피는 양에 따라 변하므로 신분증이 아니다 → **조사 미니게임에서 크기가 다른 두 조각의 밀도가 같게 나온다.**
- 혼합물은 순물질이 각자의 성질을 지닌 채 섞여 있다 → **조사 결과(어떤 특성이 다른가) = 쓸 수 있는 분리 방법.**
- 방법 선택이 **무엇이 먼저 분리되는지**를 정하고, 장치 조작이 **얼마나 깨끗하게 얻는지**를 정한다 (암석 순환의 "경로 선택 = 결과, 조작 = 특징").

### 1-2. 성공 기준
- 한 판(튜토리얼 + 필수 의뢰 3 + 최종 의뢰) **12분 내외, 최대 15분**. 근거: 암석 순환 한 판 7~9분(미니게임 4~5개) + 조사 미니게임 3개 추가.
- 한 판에 순물질 도감 6~8종 등록, 분리 방법 3종 모두 사용. 전체 도감은 여러 판 누적.
- 크롬북 1280×800 터치로 끝까지 진행 가능. 한글 어절 단위 줄바꿈 유지.
- 과학 용어·정의·수치가 교과서와 일치 (2장).

### 1-3. 범위 밖
액체 금속(28쪽), 스마트 의류(44쪽), 천연 염색 추출(46~47쪽), 원유 증류탑(41쪽), 기체 용해도 실험(22~23쪽), 잠수병(51쪽) — 퀴즈·도감 카드로만 등장하거나 부록 A 후보. 효과음·BGM(암석 순환 자산 재활용 예정).

## 2. 과학적 정확성 (반드시 유지)

교과서 표현 그대로. 상세 수치·문제는 발췌 문서.

- **물질의 특성**: 다른 물질과 구별되는 고유한 성질, **양에 관계없이 일정**. 특성 = 밀도·용해도·녹는점·끓는점. 질량·부피는 특성이 아님 (29쪽).
- **밀도 = 질량 / 부피** (g/mL, g/cm³, 1 mL = 1 cm³). 밀도가 작은 물질은 큰 물질 위로 뜬다. 값은 표 Ⅰ-1(18쪽)만: 에탄올 0.79, 물 1.00, 알루미늄 2.70, 철 7.87, 수은 13.60, 금 19.32 등. 식용유·올리브유는 교과서 값이 없으므로 **"물보다 작고 에탄올보다 크다"**(18, 50쪽)만 쓴다.
- **용해도**: 어떤 온도에서 **용매 100 g에 최대로 녹을 수 있는 용질의 질량(g)**. 대부분의 고체는 온도가 높을수록 커진다. 기체는 온도가 높을수록, 압력이 낮을수록 작아진다. 용액·용매·용질, 포화·불포화 용액.
- **녹는점·끓는점**: 일정한 압력에서 상태가 변할 때 **일정하게 유지되는 온도**. 양이 달라도 같다. 끓는점은 압력이 높으면 높아진다. 에탄올 78 ℃, 물 100 ℃, 철 녹는점 1538 ℃, 알루미늄 660 ℃.
- **순물질·혼합물**: 한 종류 / 두 가지 이상의 순물질. 혼합물은 특성이 일정하지 않다 (소금물의 끓는점은 계속 높아짐, 33쪽).
- **밀도 차 분리**: 고체는 "녹이지 않고 밀도가 두 고체의 중간인 액체"에 넣어 뜨고 가라앉힘(볍씨·소금물). 서로 **섞이지 않는** 액체는 **분별 깔때기** — 아래층은 꼭지로, 경계면은 따로, 위층은 입구로 (35쪽).
- **용해도 차 분리 = 재결정**: 고체 혼합물을 용매에 **모두 녹인 다음 온도를 낮추거나 용매를 증발**시켜 순수한 고체를 얻음. 온도에 따른 용해도 차가 **큰** 물질이 **석출**되고 거름 장치로 거른다 (37쪽).
- **끓는점 차 분리 = 증류**: 가열해 나온 기체를 냉각. **끓는점이 낮은 것이 먼저** 기화. 온도가 일정한 구간이 성분 수만큼 나타남. 끓임쪽. 한 번으로는 순수하기 어렵고 반복하면 순수해짐 (38~40쪽).
- **용어**: 비중 X(밀도), 여과 X(거름), 부력 X("밀도 차로 뜨고 가라앉는다"), 농도·크로마토그래피·승화 분리·증기 압력 X(교과서 없음). "밀도 차·용해도 차·끓는점 차", "분별 깔때기", "석출", "재결정", "증류", "끓임쪽", "거름 장치".
- 교과서에 없는 물질·수치를 만들지 않는다. 용해도 곡선 값은 교과서 그래프 축에서만 읽히므로 **곡선 모양**(질산 칼륨 가파름, 염화 나트륨 거의 평평)을 지키고 값은 `substances.json`에서 admin이 조정한다.

## 3. 화면 흐름

```
타이틀 → 인트로 (공방, 공방 주인 NPC: "특성이 곧 신분증")
  ↓
┌▶ 의뢰판 (마을 그림 위 의뢰 카드) : 의뢰 선택
│    ↓ 의뢰 NPC 대사 1~2줄
│  실험대: 성분 카드 (특성 "?" 표시)
│    ↓ 모르는 성분이 있으면
│  조사 미니게임 (30~60초) → 성분 카드 채움 + 도감 등록
│    ↓
│  갈림길: [밀도 차] [용해도 차] [끓는점 차] 문 3개 (조사 결과가 힌트로 표시)
│    ↓ 교과서 조건에 안 맞으면 한 줄 안내 후 재선택
│  분리 미니게임 (60~90초) → 얻은 순물질 도감 카드
│    ↓ 남은 혼합물이 있으면 갈림길로
│  의뢰 완료: NPC 대사 + 퀴즈 1문항
└─ 최종 의뢰 미완료면 의뢰판으로 (필수 3개 완료 시 최종 의뢰 열림)
     ↓ 최종 의뢰 완료
   엔딩: 오늘 처리한 의뢰와 방법 순서도 → 결과(별점, 새 순물질, 도감 n/N, 다시 하기)
```

- 의뢰당 약 2.5분 (대사 15초 + 조사 45초 + 갈림길 15초 + 분리 75초 + 카드·퀴즈 30초). 튜토리얼 1.5분 + 의뢰 3 × 2.5분 + 최종 3분 + 인트로·엔딩 1분 ≈ 13분.
- HUD: 현재 의뢰 이름, 단계 n/m, 별점, 경과 시간, 도감 n/N, 조사한 특성 아이콘.
- 새로고침 이어하기: 진행 중인 판을 `localStorage['matter-run-v1']`에 저장.

## 4. 의뢰와 규칙

### 4-1. 의뢰 목록 (MVP)

| # | 의뢰 (장소·NPC) | 혼합물 (교과서) | 조사 미니게임 | 분리 방법 → 얻는 것 | 쪽 |
|---|---|---|---|---|---|
| 0 튜토리얼 | 고물상 "어느 게 철이지?" | 철 조각·알루미늄 조각 (크기 2종) | **밀도 측정대** (고체) | 분리 없음. 밀도 7.87 / 2.70 확정, 크기 달라도 같은 값 | 16~17 |
| 1 필수 | 부엌 "기름이 떴어요" | 물 + 식용유 (사골국 대사) | **밀도 컵** (액체, 층 관찰) | 밀도 차(액체) → 분별 깔때기 → 식용유(위층), 물 | 18, 34~35 |
| 2 필수 | 실험실 "흰 가루 두 가지가 섞였어요" | 질산 칼륨 10 g + 염화 나트륨 2 g (시럽 병 대사) | **용해도 병** | 용해도 차 → 재결정 → 질산 칼륨(결정), 염화 나트륨(용액) | 20~22, 36~37 |
| 3 필수 | 양조장 "술에서 에탄올만" | 물 + 에탄올 (소줏고리 대사) | **가열 곡선** | 끓는점 차 → 증류 → 에탄올(78 ℃ 구간), 물(100 ℃ 구간) | 24~27, 38~40 |
| 4 최종 | 실험실 "네 가지가 섞였어요" | 물·올리브유·소독용 에탄올·정제 소금 | 없음 (도감으로 대체, 올리브유는 밀도 컵 1회) | ① 밀도 차 → 분별 깔때기 → 올리브유 ② 끓는점 차 → 증류 → 에탄올 ③ 증류 계속 → 물, **정제 소금이 남음** | 42~43, 50쪽 11번 |
| 5 선택 | 농가 "볍씨를 골라 주세요" | 볍씨 + 쭉정이 (소금물) | 없음 | 밀도 차(고체) → 소금물에 띄우기 → 쭉정이(뜸)·볍씨(가라앉음) | 34 |

- 필수 의뢰 1~3은 순서 자유. **최종 의뢰는 1~3 완료 후 열림**(최종에 쓰는 분별 깔때기·증류를 미리 익힘).
- 선택 의뢰 5는 별점 보너스. 판 시간이 15분을 넘기면 admin에서 숨김.
- 이후 추가 의뢰(부록 A): 바닷물에서 식수(증류), 천일염에서 순수한 소금(재결정), 간장+올리브유(분별 깔때기).

### 4-2. 물질 데이터 (`substances.json`)

| 항목 | 내용 |
|---|---|
| `id`, `name`, `state` | 고체·액체·기체 |
| `density` | 표 Ⅰ-1 값. 없으면 `null` + `densityRank`(정성 순위: 물 > 식용유·올리브유 > 에탄올) |
| `meltingPoint`, `boilingPoint` | 그림 Ⅰ-5·Ⅰ-7 값, 없으면 `null` |
| `solubility` | 온도별 점 배열 [{t, g}] (물 100 g 기준), 없으면 `null`. 곡선 모양은 22쪽 |
| `misciblesWithWater`, `dissolvesInWater` | 액체가 물과 섞이는지(에탄올 ○, 식용유·올리브유 ×), 고체가 물에 녹는지(소금 ○, 볍씨 ×) |
| `card` | 도감 카드: 생활 예(19, 25, 27쪽), 교과서 쪽수 |

MVP 물질: 물, 에탄올, 식용유, 올리브유, 철, 알루미늄, 질산 칼륨, 염화 나트륨(정제 소금·천일염 공용), 볍씨, 쭉정이, 소금물(용매). 자료실 카드(열람 전용): 금, 수은, 갈륨, 니켈, 산소, 질소, 헬륨, 이산화 탄소, 뷰테인, 황산 구리(Ⅱ), 질산 나트륨, 붕산, 로르산, 팔미트산.

### 4-3. 분리 판정 규칙 (`rules.ts`, 미니게임 하나 = 성분 하나 분리)

`canSeparate(mixture, method) → { ok, reason, target, remaining }`

| 방법 | 가능 조건 (교과서 근거) | 분리되는 것 | 불가 안내 (한 줄) |
|---|---|---|---|
| 밀도 차 — 고체 | 물에 녹지 않는 고체 2종 + 밀도가 중간인 액체 (34쪽) | 뜨는 고체 | "둘 다 가라앉거나 둘 다 떠요 — 밀도가 중간인 액체가 필요해요" |
| 밀도 차 — 액체 (분별 깔때기) | 서로 섞이지 않는 액체가 2층을 이룸 (35쪽) | 밀도가 작은 위층 액체 | "두 액체가 서로 잘 섞여 층이 생기지 않아요" (물+에탄올) / "고체는 층을 이루지 않아요" |
| 용해도 차 (재결정) | 물에 녹는 고체 2종, 온도에 따른 용해도 차가 서로 다름 (37쪽) | 용해도 차가 **큰** 고체(결정) | "액체는 결정으로 석출되지 않아요" / "둘 다 온도에 따라 거의 변하지 않아요" |
| 끓는점 차 (증류) | 액체 1종 이상, 섞이지 않는 액체 층이 없음 (38~40쪽) | 끓는점이 가장 낮은 액체. 녹아 있던 고체는 남음 | "기름이 층을 이루고 있어요 — 먼저 밀도 차로 걷어 내요" / "고체 두 가지뿐이라 기화하지 않아요" |

- 첫 시도에 불가 방법을 고르면 별 1개 감점, 안내 후 재선택. 갈림길에는 조사 결과가 힌트로 뜬다(예: "끓는점 78 ℃ / 100 ℃ — 다르다!").
- 최종 의뢰의 인정 순서: 분별 깔때기(올리브유) → 증류(에탄올 → 물, 소금 남음). 증류를 먼저 고르면 위 표의 "기름이 층을" 안내. 재결정을 고르면 "녹아 있는 고체가 한 가지뿐이라 가를 것이 없어요"(소금만).

### 4-4. 한 판 판정
- 필수 의뢰 3개 + 최종 의뢰 완료 = 한 판 완료 → 엔딩. 튜토리얼은 첫 판에만 자동 진입, 이후 판은 의뢰판에서 선택.
- 도감은 판을 넘어 누적(`localStorage['matter-dex-v1']`). 이미 도감에 있는 물질은 조사 미니게임을 건너뛰고 카드가 바로 채워진다 → 2번째 판부터 짧아짐.

## 5. 미니게임

공통: 탭·드래그·길게 누르기(크롬북 터치) + 키보드 대체. 0~3별, 의뢰 퀴즈 정답 +1별. 수치는 전부 `minigame-config.json`. 정밀 드래그형(밀도 측정대·밀도 컵·용해도 병·분별 깔때기)은 암석 순환 광물 실험대(`MineralOverlay`) 방식의 React 오버레이, 실시간 그래프·낙하·타이밍형(가열 곡선·증류·재결정·띄우기)은 Phaser 씬. 최종 결정은 계획서에서.

### 5-1. 조사 미니게임 (성분 카드 채우기)

1. **밀도 측정대** (고체, ~60초, 16~17쪽)
   - 조각을 **전자저울**에 드래그 → 질량 표시. **눈금실린더**에 물이 들어 있고(처음 부피 표시), 조각을 실로 묶어 넣으면 수면이 올라감.
   - **눈높이 슬라이더**를 수면에 맞추면 눈금이 선명해지고 오목한 면의 값을 읽을 수 있다(17쪽 규칙). 어긋난 채 읽으면 오차.
   - 늘어난 부피 = 조각의 부피 → 밀도 = 질량/부피가 자동 계산되어 표 Ⅰ-1과 대조, 물질 확정.
   - **크기가 다른 조각 2개**를 재면 같은 밀도 → "양에 관계없이 일정" 말풍선. 튜토리얼은 철·알루미늄 큰·작은 조각 4개 중 3개 이상.
   - 별점: 눈높이 정확도 + 걸린 시간.
2. **밀도 컵** (액체, ~30초, 18쪽)
   - 액체를 컵에 붓는다(벽면을 타고 천천히 — 빠르게 부으면 섞여 잠시 뿌옇게). 층이 나뉘면 각 층에 이름표를 드래그해 붙인다.
   - 결과: 물이 아래, 식용유·올리브유가 위 → 성분 카드에 "밀도: 물보다 작다". 동전(가라앉음)·얼음 떨어뜨리기는 연출.
3. **용해도 병** (~45초, 21~22쪽)
   - 물 10 g이 든 병에 **약숟가락으로 0.5 g씩** 넣고 자석 젓개 버튼으로 젓는다. 더 이상 녹지 않으면 바닥에 가루가 남는다 → 실온 최대량 기록.
   - **60 ℃ 물 비커에 병을 담그면**(드래그) 남은 가루가 녹고 더 넣을 수 있다 → 60 ℃ 최대량 기록.
   - 두 물질을 차례로 → 용해도 곡선 위에 점 4개가 찍히고 "온도에 따른 용해도 차가 큰 것 = 질산 칼륨" 판정. 값은 `substances.json` 곡선에서 계산(교과서 탐구 2: 질산 칼륨 6 g은 실온에선 다 안 녹고 60 ℃에서 녹음).
4. **가열 곡선** (~45초, 24·26쪽)
   - 물질을 가열대에 올리면 온도-시간 그래프가 실시간으로 그려진다. **평평해지는 순간 버튼**을 누르면 그 온도가 녹는점·끓는점으로 기록. 너무 이르거나 늦으면 오차.
   - 같은 물질을 **양을 바꿔** 다시 가열해도 같은 온도 → "양에 관계없이 일정". 의뢰 3에서는 물(100 ℃)과 에탄올(78 ℃).
   - 별점: 버튼 타이밍 오차.

### 5-2. 분리 미니게임 (갈림길 방법별)

1. **분별 깔때기** (밀도 차 — 액체, ~75초, 35쪽)
   - 혼합물을 넣고 마개를 닫는다. **기다리기**: 두 층이 천천히 나뉜다. 깔때기를 흔들면(드래그) 다시 섞여 시간이 늘어난다.
   - 마개를 연 뒤 **꼭지를 길게 눌러** 아래층을 비커 (가)에 받는다. **경계면이 꼭지에 가까워질 때 놓기** → 경계면 액체는 작은 비커에 따로 → 남은 위층은 깔때기를 기울여 **입구로** 비커 (나)에.
   - 순도 = 경계면 처리 정확도. 마개를 닫은 채 꼭지를 열면 액체가 내려오지 않는 연출(교과서 순서).
2. **재결정** (용해도 차, ~75초, 36~37쪽)
   - 혼합물을 물 10 mL 비커에 넣고 **가열 + 유리 막대 젓기**(탭 연타) → 온도 게이지가 오르고 용해도 곡선 위에서 두 물질 점이 곡선 아래로 들어가면 "모두 녹음".
   - 비커를 **얼음 비커로 드래그** → 온도가 내려가며 질산 칼륨 점이 곡선을 넘는 순간부터 결정이 내려앉음(석출). 염화 나트륨은 그대로 용액에.
   - 다 녹기 전에 냉각하면 섞인 채 가라앉아 순도 하락. 냉각 후 **거름 장치에 붓기** → 거름종이 위 결정(질산 칼륨), 통과한 용액(염화 나트륨). 증류수로 씻기(탭)는 보너스 순도.
3. **증류** (끓는점 차, ~90초, 38~40쪽)
   - 준비: **끓임쪽 넣기**(빠뜨리면 끓어 넘쳐 재시작), 온도 센서 위치 확인(가지 부분), 시험관을 얼음물에.
   - **가열 세기 다이얼**로 온도 그래프를 올린다. 그래프가 **평평해지는 첫 구간(78 ℃)**에서 시험관을 (가)→(나)로 교체, 온도가 다시 오르면 (다), **두 번째 평평 구간(100 ℃)**에서 (라). 시험관 교체는 시험관대 탭.
   - 냉각수(얼음물)가 미지근해지면 얼음 아이콘을 탭해 보충 — 놓치면 기체가 달아나 양이 줄어든다.
   - 확인 연출: (나)에 유리 막대 → 에탄올 냄새 말풍선, (라)에 푸른색 염화 코발트 종이 → 붉게. 순도 = 구간 안에서 교체한 정확도.
   - 최종 의뢰에서는 같은 씬에서 에탄올·물을 차례로 얻고 **플라스크에 정제 소금이 남는** 연출로 3단계 완료(50쪽 11번).
4. **소금물에 띄우기** (밀도 차 — 고체, ~60초, 34쪽, 선택 의뢰)
   - 볍씨·쭉정이 섞인 것을 소금물 통에 붓는다 → 쭉정이가 떠오르고 볍씨는 가라앉는다. 떠오른 것을 **체로 드래그해 걷어** 낸다(낙하·부상 타이밍). 볍씨를 함께 걷으면 감점.

## 6. 주인공·도감

- 주인공 = **공방 견습생** 1명 (정면 1장 + 표정 2장: 기본·성공). 의뢰 NPC 5명(공방 주인, 고물상, 요리사, 실험실 연구원, 양조장 장인) + 농부(선택 의뢰).
- **물질 도감** (`game/dex.ts`, 누적)
  - "얻은 순물질" 칸: 물, 에탄올, 식용유, 올리브유, 철, 알루미늄, 질산 칼륨, 염화 나트륨 (+ 볍씨·쭉정이는 사례 카드). 카드 항목: 상태, 밀도(값 또는 정성), 녹는점·끓는점, 용해도 곡선, 물과 섞임/녹음, 생활 예, 교과서 쪽수, **얻은 방법 도장**(측정·분별 깔때기·재결정·증류).
  - "분리 방법" 칸 3개(밀도 차·용해도 차·끓는점 차) + 사례 카드 9장(사골국·볍씨·기름 유출·시럽 병·천일염·소줏고리·향료·원유 증류탑·바닷물 식수, 34~41쪽).
  - "자료실": 교과서 수치 표(밀도·녹는점·끓는점, 18·25·26쪽) 열람 전용.
  - 저장 `localStorage['matter-dex-v1']` (진행 판 저장과 분리). 저장 실패 시에도 게임 진행.

## 9. 코드 구성

`snug-electricity-game` 뼈대와 같은 설정에서 시작한다 (dev 포트 3300 제안 — 혈액 3000, 암석 3100, 전기 3200).

**가져올 것** (`../snug-rock-cycle-game`): `game/systems/`(render, placeholders, sceneRouter, validators), `game/dataStore.ts`, `phaserConfig.ts`, `audio.ts`, `components/`(GameContainer, HUD, UIOverlay, TopControls, AudioRunner, DialogBox, QuizOverlay), `MineralOverlay`의 포인터·문지르기·드롭 판정 코드(조사·분별 깔때기 오버레이의 바탕), `app/admin`, `app/api/admin`, `scripts/`.

**새로 만들 것**
- `game/rules.ts` — 순수 함수: `canSeparate`, 최종 의뢰 순서 판정, 의뢰 잠금 판정, 조사 필요 여부(도감 대조), 별점 계산. 게임 규칙의 단일 출처.
- `game/store.ts` — 단계: `title → intro → board → accept → investigate → choose → separate → result → quiz → board … → ending → summary`. 전이는 `start/next/acceptMission/finishInvestigation/chooseMethod/completeMinigame/finishQuiz/restartRun/reset`만.
- `game/scenes/` — `BoardScene`(의뢰판), `BenchScene`(실험대·갈림길 배경), `HeatingCurveScene`, `DistillScene`, `RecrystalScene`, `FloatScene`.
- `components/overlays/` — `DensityBenchOverlay`(측정대·컵), `SolubilityOverlay`, `FunnelOverlay`(분별 깔때기), `MethodChoiceOverlay`(갈림길), `SubstanceCardView`(도감 카드), `MissionBoardOverlay`, `EndingOverlay`, `ResultOverlay`.
- `game/dex.ts` — 도감 누적 저장.

개발 모드 콘솔 훅: `__store`, `__game`, `__rules`. 씬 수정 후 전체 새로고침.

## 10. 오류 처리

- 이미지 없음 → 플레이스홀더(색 도형 + 이름). 장치 그림은 SVG 코드로 먼저(광물 실험대 방식).
- JSON 검증 실패 → 개발 모드 오류 표시, 배포는 빌드 전 테스트로 차단.
- localStorage 읽기·쓰기 try/catch, 실패해도 한 판 진행.
- 의뢰 데이터가 4-3 규칙으로 풀 수 없으면 로드 시 검증 실패(무한 갈림길 방지).
- admin 저장 production 403.
