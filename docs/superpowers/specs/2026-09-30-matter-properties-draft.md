## 1. 학습 핵심

**"물질의 특성은 양에 관계없이 물질마다 정해져 있다. 그래서 특성으로 물질을 알아내고, 특성의 차이로 섞인 것을 가른다."**

- 밀도·용해도·녹는점·끓는점 네 가지가 물질의 **신분증**이다. 질량·부피는 양에 따라 변하므로 신분증이 아니다.
- 혼합물은 순물질이 **각자의 성질을 지닌 채** 섞여 있다 → 성질의 **차이**를 이용하면 다시 가를 수 있다.
- 게임에서는 **특성 조사 = 물질의 신분 확인**, **어떤 특성 차를 쓸지 선택 = 분리 방법**, **장치 조작 결과 = 얻은 순물질의 순도와 양**.
- 암석 순환의 원칙 "경로 선택 = 결과, 조작 결과 = 특징"을 그대로 잇는다. 여기서는 "방법 선택 = 무엇이 먼저 분리되는가, 조작 = 얼마나 깨끗하게".

## 2. 과학적 정확성 (반드시 유지)

교과서 용어·정의를 그대로 쓴다. 상세는 발췌 문서 2장.

| 개념 | 게임에서 지킬 것 |
|---|---|
| 물질의 특성 | 다른 물질과 구별되는 고유한 성질, **양에 관계없이 일정**. 질량·부피는 특성이 아님 (29쪽) |
| 밀도 | 질량/부피 (g/mL, g/cm³). 작은 것이 큰 것 위로 뜸. 값은 표 Ⅰ-1 (18쪽)만 사용 |
| 용해도 | 어떤 온도에서 용매 100 g에 최대로 녹는 용질의 g. 대부분 고체는 온도↑ 용해도↑. 기체는 온도↑·압력↓이면 용해도↓ |
| 녹는점·끓는점 | 상태 변화 중 일정하게 유지되는 온도. 양이 달라도 같음. 끓는점은 압력↑이면↑ |
| 순물질·혼합물 | 한 종류 / 두 가지 이상 순물질. 혼합물은 특성이 일정하지 않음 (소금물 끓는점) |
| 밀도 차 분리 | 고체: 녹이지 않고 밀도가 중간인 액체. 액체: 서로 섞이지 않는 것만, 분별 깔때기 (아래층 꼭지, 경계면 따로, 위층 입구) |
| 용해도 차 분리 | **재결정**: 모두 녹인 뒤 냉각(또는 용매 증발) → 용해도 차 **큰** 물질이 **석출** → 거름 |
| 끓는점 차 분리 | **증류**: 가열해 나온 기체를 냉각. 끓는점 **낮은** 것이 먼저. 온도 일정 구간이 성분 수만큼. 끓임쪽. 한 번으로는 순수하기 어려움 |
| 용어 | 비중 X(밀도), 여과 X(거름), 부력 X(밀도 차로 뜨고 가라앉음), 농도·크로마토그래피·승화 분리 X(교과서 없음). 증발은 재결정 안의 한 방법 |

- 교과서에 없는 물질·수치를 게임에 넣지 않는다. 식용유·올리브유 밀도는 교과서에 값이 없으므로 "물보다 작고 에탄올보다 크다"만 쓴다 (18, 50쪽).
- 용해도 곡선 수치는 교과서 그래프 축에서만 읽히므로 게임 데이터는 곡선 **모양**(질산 칼륨 가파름, 염화 나트륨 평평)을 지키고 값은 admin에서 조정한다.

## 3. 게임 한 줄 요약

주인공은 마을 **"분리 공방"의 견습생**. 마을 사람들이 **섞여 버린 것**을 들고 찾아온다(볍씨와 쭉정이, 기름 뜬 사골국, 흰 알갱이가 생긴 시럽, 바닷물에서 식수…). 견습생은 섞인 물질들의 **특성을 조사**하고, **밀도 차·용해도 차·끓는점 차 중 무엇을 쓸지 고른** 뒤, 장치를 **직접 조작**해 순물질을 하나씩 꺼낸다. 얻은 순물질은 **물질 도감**에 특성 값과 함께 등록된다. 마지막 의뢰는 네 가지가 섞인 혼합물을 **3단계로 설계**해 가르는 것(교과서 42~43쪽).

## 4. 구조 (의뢰판 + 공방, `WorkshopScene`)

암석 순환은 "순환 지도"가 과학 구조였다. 이 단원의 과학 구조는 **"혼합물 → 어떤 특성 차? → 무엇이 먼저 나오나"**라는 **분리 순서도**다. 따라서 월드맵 대신 **의뢰판**(마을 장소들)과 **공방 실험대**(방법 선택 + 조작)로 짠다.

```
[의뢰판: 마을]                      [공방 실험대]
  농가 ── 볍씨·쭉정이 ─────┐         혼합물 카드 (성분·상태·특성 조사 결과)
  부엌 ── 기름 뜬 사골국 ──┤              │
  냉장고 ── 흰 알갱이 시럽 ┼──▶  갈림길: [밀도 차] [용해도 차] [끓는점 차]
  바닷가 ── 바닷물→식수 ───┤              │ 선택 = 무엇이 먼저 분리되는가
  실험실 ── 4가지 혼합물 ──┘         미니게임 (조작 = 순도·양)
                                          │
                                   순물질 도감 등록 → 남은 혼합물이 있으면 갈림길로 복귀
```

- **의뢰 하나 = 혼합물 하나.** 성분이 2개면 1단계, 3~4개면 2~3단계. 단계마다 갈림길로 돌아온다.
- **갈림길에서 잘못된 방법을 고르면** 교과서 근거로 막힌다: 물+에탄올에 분별 깔때기 → "두 액체가 서로 잘 섞여 층이 생기지 않아요"(35쪽 조건), 볍씨를 물에 → "둘 다 가라앉아요"(34쪽 밀도 중간 조건), 질산 칼륨+염화 나트륨에 증류 → "둘 다 고체라 기화하지 않아요". 별 감점 후 재선택.
- **성분 조사**는 갈림길 전에 한다: 성분 카드를 뒤집으면 특성 값이 보이는데, 처음엔 "?"이고 **조사 미니게임**(밀도 측정대·가열 곡선·용해도 병)으로 채운다. 한 번 조사한 물질은 도감에 남아 다음 의뢰부터 바로 보인다 → 도감이 쌓일수록 조사가 줄고 판단이 빨라진다.
- **출발 의뢰**는 튜토리얼 성격: 백금 반지와 은반지 구별(16쪽 도입) — 밀도 측정대만으로 끝나는 "특성은 양과 무관" 체험. 이후 의뢰는 자유 선택, 마지막 실험실 의뢰는 의뢰 3개 이상 완료 후 열림.

## 5. 미니게임

### 5-1. 분리 미니게임 (갈림길 방법별)

| 방법 | 미니게임 (가칭) | 조작 | 결과가 결정하는 것 |
|---|---|---|---|
| 밀도 차 (고체) | **소금물에 띄우기** | 담글 액체를 고르고(물·소금물·에탄올·식용유) 붓는다. 뜬 것을 **체로 걷어** 낸다 | 액체가 "녹이지 않고 밀도가 중간"이면 분리 성공. 걷는 타이밍·놓친 개수 → 순도 |
| 밀도 차 (액체) | **분별 깔때기** | 혼합물을 넣고 **기다린다**(흔들면 다시 섞임) → 꼭지를 열어 아래층을 받다가 **경계면에서 멈춤** → 경계면은 따로 → 위층은 입구로 | 경계면 처리 정확도 → 두 액체의 순도 |
| 용해도 차 | **재결정** | 가열·젓기로 **모두 녹이기**(온도 게이지가 용해도 곡선 위로) → 얼음물에 **냉각** → 결정이 내려앉으면 **거름 장치**에 붓기 | 냉각 온도에 따라 석출량(곡선 차이가 큰 물질만 결정으로). 다 녹이기 전에 냉각하면 섞인 채 석출 |
| 끓는점 차 | **증류** | 끓임쪽 넣기 → 가열 세기 조절 → 실시간 온도 그래프가 **평평해지는 구간**에서 시험관 교체(가~라) → 냉각수(얼음물) 유지 | 구간을 놓치면 두 물질이 섞인 시험관. 냉각 안 하면 기체가 달아남. 순도 = 구간 맞춘 정확도 |

- 미니게임 1개 60~90초. 조작은 암석 순환의 광물 감별 실험대(드래그·문지르기·누르기)와 같은 포인터 방식으로 크롬북 터치 대응.
- 성공 연출은 교과서 확인 방법을 따른다: 증류 (나) 시험관은 에탄올 냄새 말풍선, (라)는 푸른색 염화 코발트 종이가 붉게. 재결정은 거름종이 위 결정 클로즈업.

### 5-2. 조사 미니게임 (성분 카드 채우기)

| 특성 | 미니게임 | 조작 | 결과 |
|---|---|---|---|
| 밀도 | **밀도 측정대** (16~17쪽) | 조각을 전자저울에 올려 질량 → 눈금실린더에 담가 늘어난 부피(눈높이 맞추고 오목한 면 읽기) → 밀도 계산 | 표 Ⅰ-1과 대조해 물질 확정. 크기 다른 조각을 주면 같은 값이 나오는 것을 체험 |
| 녹는점·끓는점 | **가열 곡선** (24, 26쪽) | 가열하면 그래프가 그려지고 **평평한 구간에서 버튼** | 구간 온도 = 녹는점/끓는점. 양을 바꿔도 같음 |
| 용해도 | **용해도 병** (21쪽) | 0.5 g씩 넣고 자석 젓개로 젓기, 안 녹으면 온도 올리기 | 온도별 최대량 → 곡선 위 점. 기체는 탄산음료 변형(뜨거운 물·감압) |

- MVP에서는 **밀도 측정대만** 조사 미니게임으로 넣고, 녹는점·끓는점·용해도는 도감 카드에 값을 미리 넣어 준다 (결정 필요 2).

## 6. 진행·보상

- **물질 도감**: 순물질 카드 — 밀도·녹는점·끓는점·용해도(곡선), 상태, 교과서 생활 예. 교과서에 값이 있는 물질만: 물, 에탄올, 철, 알루미늄, 금, 수은, 갈륨, 니켈, 염화 나트륨, 질산 칼륨, 황산 구리(Ⅱ), 질산 나트륨, 붕산, 산소, 질소, 헬륨, 이산화 탄소, 뷰테인, 로르산, 팔미트산 + 값 없는 생활 물질(식용유·올리브유·소금물·볍씨) 별도 표시.
- **분리 방법 도감** 3칸(밀도 차·용해도 차·끓는점 차) + 사례 카드(사골국·볍씨·기름 유출·천일염·시럽·소줏고리·향료·원유 증류탑·바닷물 식수).
- **한 판 = 의뢰 4~5개, 10분 내외 (최대 15분).** 튜토리얼 의뢰 1 + 방법별 의뢰 3 + 실험실 3단계 의뢰 1. 근거: 암석 순환 한 판 미니게임 4~5개 7~9분.
- 별점: 순도(조작) + 방법 선택 첫 시도 성공 + 의뢰 후 퀴즈(교과서 스스로 확인하기·마무리 문제 기반, 발췌 3장).
- 엔딩: 오늘 처리한 의뢰와 사용한 방법 순서도 요약, 도감 진행률.

## 7. 기술 (암석 순환 구조 재사용)

- Next.js 16 + Phaser 4 + zustand (`game/store.ts` 전이 액션만). `game/rules.ts`에 **분리 가능 판정 순수 함수**: `canSeparate(mixture, method) → { ok, reason(교과서 쪽수), first: 성분 }`.
- 편집 가능한 콘텐츠는 `public/data/*.json`: `substances.json`(특성 값), `mixtures.json`(의뢰·성분·정답 순서), `dialog-config.json`, `quiz-pool.json`, `minigame-config.json`(시간·판정 폭).
- `/admin` 탭: 물질·의뢰·대화·퀴즈·미니게임. 저장 POST는 production에서 403.
- 테스트(Vitest): `rules` 판정표(물+에탄올→분별 깔때기 불가, 볍씨+물 불가 등), 증류 구간 판정, 재결정 석출량, JSON 검증.
- 그림: 공방 배경 1, 마을 의뢰판 1, 장치 5(분별 깔때기·재결정 세트·증류 장치·눈금실린더+저울·가열대), NPC 6, 물질 아이콘 20종 — 플레이스홀더 먼저, `scripts/gen_image.sh`로 교체.

5. **의뢰 목록** — 스펙 v1 제안: 철·알루미늄 조각(튜토리얼) / 물+식용유(분별 깔때기) / 질산 칼륨+염화 나트륨(재결정) / 물+에탄올(증류) / 물·올리브유·소독용 에탄올·정제 소금(최종 3단계) + 볍씨·쭉정이(선택).
6. **저장소 이름** — 제안: `snug-matter-properties-game`.
7. **순서** — 전기와 자기(뼈대 완료)와 이 게임 중 먼저 구현할 것. 미정.
