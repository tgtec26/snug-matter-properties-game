## 메모 (2026-09-30)
- NPC 시트는 Codex가 투명·초록 배경 요청을 무시하고 어두운 배경을 넣어 줌 → 지금은 칸별 **정사각 초상 크롭**(`public/assets/npc/*.webp`)으로 사용. 전신 컷아웃이 필요하면 크로마키 배경(#00B140) 재요청 또는 배경 제거 도구 필요.
- 아이템 시트는 투명 배경으로 잘 나옴 (`public/assets/items/*.webp`).
