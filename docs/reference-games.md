# 레퍼런스 게임 조사 (물질 분리 공방)

지침 9번 "레퍼런스 게임 조사 필수"에 따른 기록이다.

- 작성: 2026-09-30. **회고 조사**다. 이 게임은 조사 전에 스펙 승인과 구현이 끝났다. 그래서 "스펙에 반영"이 아니라 **이미 닮은 점**과 **아직 빌려 오지 않은 점**으로 나눠 적는다.
- 출처와 한계: 웹 검색 요약만 썼다. PhET 공식 사이트는 이 세션의 네트워크에서 열리지 않아(접속 차단) 공식 설명을 직접 읽지 못했고, 교육 자료 사이트와 상점 페이지의 설명에 나온 내용만 적었다. 직접 플레이해서 확인한 것은 없다. 행마다 확인 수준을 적었다.
- "아직 빌려 오지 않은 점"은 제안일 뿐 결정이 아니다. 교과서 범위를 벗어나는 것은 제안하지 않았다.

## 1. PhET 밀도 (Density)

| 항목 | 내용 |
|---|---|
| 핵심 재미 | 블록을 저울에 올려 질량을 재고, 물에 넣어 눌러서 부피를 읽고, 놓으면 뜨는지 가라앉는지 본다. 질량이나 부피를 바꿔도 밀도는 그대로다. 바꿀수록 블록이 물속에서 더 잠기거나 떠오른다. |
| 확인 수준 | 교육 자료 사이트의 활동지 요약 (wizer.me, TISS 활동지). 공식 페이지 미확인 |
| 이 게임에서 닮은 점 | 밀도 측정대(`DensityBench`: 재고 계산), 밀도 컵(`DensityCup`: 기울여 붓기, 이름표 드래그), 소금물에 띄우기(`FloatSieve`). 학습 핵심 "양에 관계없이 일정"(AGENTS.md) |
| 아직 빌리지 않은 점 | "양을 바꿔도 밀도는 같다"를 **학생이 양을 바꿔 보고 눈으로 확인**하는 조작. 측정대에 그 조작이 있는지는 이번에 확인하지 않았다 |

## 2. PhET 설탕·소금 용액 (Sugar and Salt Solutions)

| 항목 | 내용 |
|---|---|
| 핵심 재미 | 설탕을 붓고 소금을 흔들어 넣고 물을 증발시키며 농도와 전도도가 변하는 것을 본다. 더 녹지 않고 남는 때가 포화다. 전도도 측정기를 꺼내 전구 밝기를 본다. 미시 화면에서는 소금이 이온으로 나뉘고 설탕은 나뉘지 않는다 |
| 확인 수준 | 교육 자료 사이트 요약 (spoken-tutorial, TISS 교사용 안내서). 공식 페이지 미확인 |
| 이 게임에서 닮은 점 | 용해도 병(`SolubilityBottle`: 약숟가락으로 넣고 온도를 바꿈, 더 안 녹고 남으면 포화), 재결정(`Recrystal`: 가열·냉각·거름·씻기) |
| 아직 빌리지 않은 점 | 안쪽 입자를 들여다보는 화면. 교과서 Ⅰ단원(과학2)이 용해도를 입자로 설명하는 범위는 확인하지 않았으므로 **채택 여부는 교과서 확인 뒤** 정한다 |

## 3. Potion Craft: Alchemist Simulator

| 항목 | 내용 |
|---|---|
| 핵심 재미 | 재료를 절구로 **곱게 갈고**(간 정도가 결과에 영향) 가마솥에 섞는다. 연금 지도에서 경로를 정해 효과를 조합한다. 매일 손님이 문제를 들고 오고, 무엇을 팔았는지에 따라 결과가 생긴다. 도구와 재료를 손으로 다루는 느낌을 강조한다 |
| 확인 수준 | Epic Games 상점 페이지 설명 |
| 이 게임에서 닮은 점 | 공방 세계관과 의뢰판(손님 의뢰), 방법 선택 = 무엇이 먼저 분리되는가, **조작 결과 = 순도**(AGENTS.md 학습 핵심). 조작 세기가 결과의 품질을 바꾸는 구조 |
| 아직 빌리지 않은 점 | 손님의 반응이 결과에 따라 갈리는 연출(의뢰인 NPC는 정사각 초상뿐). 그림 교체 때 표정 차이를 넣으면 같은 효과를 낼 수 있다 |

## 4. Cooking Mama (닌텐도 DS)

| 항목 | 내용 |
|---|---|
| 핵심 재미 | 요리 한 단계가 곧 미니게임이고, 한 번에 10초 안팎이다. 재료를 잡기, 끌어서 달걀 깨기, 원을 그려 뭉치기, 문지르기 같은 **터치 동작이 요리 행동과 닮았다**. 짧은 미니게임이 이어지는 구조라 규칙 설명이 거의 필요 없다 |
| 확인 수준 | 위키·리뷰 사이트 요약 (StrategyWiki, Games Asylum). 직접 플레이 안 함 |
| 이 게임에서 닮은 점 | 미니게임 8개를 의뢰 안에서 이어 가는 구조, 기울여 붓기·이름표 끌기·시험관 교체처럼 실험 행동과 닮은 조작 |
| 아직 빌리지 않은 점 | 한 단계 끝날 때마다 **즉시** 주는 짧은 평가(등급·칭찬) 연출. 지금은 의뢰 끝에 별로 모아서 준다 |

## 5. 정리

- 이 게임의 골격(공방 + 의뢰 + 조사→방법 선택→분리 조작→순도)은 위 네 가지와 잘 맞고, 특히 밀도 측정·용해도 조작은 PhET 계열과 같은 문법이다.
- 후속으로 검토할 만한 것 (결정 아님): 양을 바꿔 보는 밀도 확인 조작, 의뢰인 표정 차이, 단계 끝 즉시 평가. 입자 화면은 교과서 범위 확인이 먼저다.
